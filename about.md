# À propos de Touché-Coulé

**Touché-Coulé** est le grand classique de la bataille navale, développé par
**Geoffroy Streit** (alias **Hylst**).

## Le jeu

Placez votre flotte de 5 navires sur une grille 10×10, puis affrontez l'ennemi à
l'aveugle : chacun vise les eaux de l'autre à tour de rôle jusqu'à ce qu'une flotte entière
coule. Trois armes tactiques viennent compléter le canon standard : le scan sonar (révèle
une zone 3×3 sans consommer de tour), la salve aérienne (frappe en croix) et la torpille
(tire en ligne depuis la case visée jusqu'à toucher quelque chose).

« Touché-coulé » est l'exclamation traditionnelle du jeu, prononcée quand un navire est
définitivement détruit.

## Stack technique

- React 19, TypeScript 5.9 (strict), Tailwind CSS 4
- Vite 7, vite-plugin-singlefile
- Logique de jeu pure (`game.ts`), rendu React
- Web Audio API pour les effets sonores
